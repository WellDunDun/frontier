# Changelog

All notable changes to Frontier are documented in this file.

## 0.1.0 - 2026-06-11

- Initial public preview of the Frontier Claude Code plugin.
- Added provider-backed delegation through Pi and Codex harnesses.
- Added backend resolution for oMLX, Ollama, and explicit OpenAI-compatible servers.
- Added job tracking, background task status/result/cancel commands, and session-aware defaults.
- Added runtime guardrail tests and plugin validation checks.
